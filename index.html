Methodology & Loop Pipeline

The Research Agent & Human-in-the-Loop Architecture

A multi-tiered verification pipeline designed to prevent agent hallucinations, catch developer portal redirects, and cleanly surface gated enterprise sales requirements.

Autonomous Pipeline Topology Rough.js Engine
What the Agent Handled Autonomously
  • Broad-Spectrum Extraction: Parsed 100 integration docs, SDK references, and community repos in parallel via Composio SDK & Gemini Flash.
  • Automated Liveness Testing: Tested HTTP status codes across all 100 documentation URLs. Automatically remediated 14 broken or redirected links using Firecrawl scraping.
  • MCP Ecosystem Discovery: Cross-referenced GitHub and official registries, identifying 18 official MCP servers and 39 community MCP wrappers.
  • Strict Schema Validation: Enforced normalized auth types, buildability tiers, and access models across all 100 structured outputs.
Where a Human Was Required
  • The "Fake Self-Serve" Gating Trap: Identifying that Google Ads and Meta Ads allow instant sandbox signups, but require human App Review and business phone verification before mutating live data.
  • CLI vs Cloud Disambiguation: Catching that tools like Mermaid CLI have no hosted REST API, but run entirely as local binaries.
  • Enterprise Gate Nuances: Confirming that platforms like DealCloud, Gladly, and PitchBook lack public developer consoles and require licensed customer admin enablement.
  • Multi-Tenancy Verification: Resolving whether third-party connectors (e.g. Fanbasis, iPayX) were official developer APIs or wrapper services.
